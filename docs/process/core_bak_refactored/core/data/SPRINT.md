# SPRINT迭代计划与跟踪（数据模块）

说明：本模块用于统一的数据质量评估与治理能力的迭代计划与进展跟踪。仅维护迭代计划与进展，未分配事项在同目录 TODO.md 维护。

- 迭代1：数据质量评估服务（P1 - 规划中）
  - 入口文件（计划）：`core_bak_refactored/core/data/data_quality_monitor.py`
  - 迭代目标（收敛版）
    - 提供统一的数据质量评估服务（完整性/一致性/时效性/可靠性）
    - 产出质量报告对象（quality_report）与质量标识（quality_flags）供业务模块消费
    - 规则与阈值配置由专家提供（禁止默认硬编码）
  - 进展跟踪
    - 状态：🔄 规划中（从 risk 模块迁移职责，建立统一服务）
    - 依赖：专家配置与规范文档（ask/answer 流程）
  - 验收断言
    - 单元测试覆盖完整性/一致性/时效性 3类检查（≥95%通过率）
    - 质量标识输出外部化，可被 `core/risk` 的 `report_snapshot` 引用
    - 规则与阈值由配置驱动（来自专家答复），不在代码中设默认值
  - 外部协作
    - 消费方：`core/risk`（只消费 quality_flags，不自定义规则）
    - 配置来源：`docs/consultation.md`（专家答复）及配置文件

- 迭代2：质量评估配置加载与校验（P1 - 规划中）
  - 迭代目标
    - 定义 `DataQualityPolicy` 规则集与阈值（专家提供）
    - 实现配置加载、校验与热更新钩子（可选）
  - 验收断言
    - 配置正确加载率100%，错误配置能给出明确校验错误
    - 与 `DataQualityMonitor.validate` 无缝对接（策略正确应用）

备注：进行中的迭代必须标记为🔄 IN_PROGRESS，禁止在迭代完成前标记为✅ COMPLETE；跨模块职责遵循规范 `PECIFICATIONS.md`：数据质量规则与默认值须由专家确认，业务模块不得自行设定。
