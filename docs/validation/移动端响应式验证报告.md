## 响应式CSS特性分析

### 1. CSS 变量系统

采用响应式 CSS 变量，根据屏幕尺寸自动调整：

```css
/* 默认（桌面） */
--font-size-base: 16px;
--spacing-md: 12px;
--spacing-lg: 16px;

/* 平板 (max-width: 1024px) */
--font-size-base: 15px;
--spacing-lg: 14px;

/* 移动 (max-width: 768px) */
--font-size-base: 14px;
--spacing-md: 10px;
--spacing-lg: 12px;

/* 小屏手机 (max-width: 480px) */
--font-size-base: 13px;
--spacing-sm: 6px;
```

### 2. 网格布局响应

```css
/* 平板：2列 */
@media (max-width: 1024px) {
    .grid-3, .grid-4 {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* 移动：全部单列 */
@media (max-width: 768px) {
    .grid-2, .grid-3, .grid-4, .grid {
        grid-template-columns: 1fr;
        gap: var(--spacing-md);
    }
}
```

### 3. 导航栏适配

**平板** (1024px以下):
- 隐藏导航链接：`.header-nav { display: none; }`
- 保留品牌和状态指示器

**移动** (768px以下):
- 垂直堆叠布局：`flex-direction: column;`
- 品牌和状态占据全宽
- 更小的字体和间距

### 4. 触摸设备优化

```css
@media (hover: none) and (pointer: coarse) {
    /* 按钮最小点击区域 44px (iOS HIG 标准) */
    .btn, .nav-link {
        min-height: 44px;
    }
    
    /* 禁用 hover 变换 */
    .btn:hover, .nav-link:hover {
        transform: none;
    }
    
    /* 触摸反馈 */
    .btn:active, .nav-link:active {
        opacity: 0.7;
    }
}
```

### 5. 表单输入优化

```css
@media (max-width: 768px) {
    .form-control {
        font-size: 16px; /* 防止 iOS 自动缩放 */
        padding: var(--spacing-md);
    }
}
```

### 6. 表格滚动

```css
@media (max-width: 768px) {
    .table-responsive {
        overflow-x: auto;
        -webkit-overflow-scrolling: touch; /* iOS 平滑滚动 */
    }
}
```
