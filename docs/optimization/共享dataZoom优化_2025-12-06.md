## 一、问题描述

### 用户反馈

> "为什么在切换技术指标的时候，整个数据窗口都发生了变化，并且，k线图会重新刷新？k线和技术指标现在是采用事件同步的方式控制两个数据窗口的一致性吗？二者可否共享一个数据窗口，使得滚动条的控制更加简单？"

### 问题分析

#### 问题1：切换指标时重新加载数据

**原代码（第 891 行）**：
```javascript
btn.onclick = () => {
    // ...
    currentIndicator = ind
    if (currentIndex) loadKline(currentIndex.id)  // ❌ 重新加载数据

**导致的问题**：
1. ❌ 重新请求 API（不必要，数据已在 `allKlineData` 中）
2. ❌ K 线图重新渲染（不必要，只需更新指标图）
3. ❌ 数据窗口位置可能变化（虽然已保存，但仍有闪烁）

#### 问题2：使用轮询方式同步 dataZoom（效率低）

- 代码复杂（同步逻辑和无限滚动逻辑混合）

#### 问题3：两个独立的 dataZoom 需要手动同步

**当前架构**：
```
┌─────────────┐       轮询检测       ┌─────────────┐
│  K 线图     │  ─────────────>      │  指标图      │

**问题**：
- 需要手动检测差异
- 需要手动同步
- 需要防止循环同步（`isSync` 标志）

## 二、解决方案

### 核心思路

**使用 ECharts connect API**，让两个图表自动共享 dataZoom 组件。

### 技术原理

ECharts 提供了 `echarts.connect()` API，可以让多个图表实例：
- **共享工具栏**（toolbox）
- **共享 dataZoom**（自动同步）
- **共享 tooltip**（联动显示）

**只需一行代码**：
```javascript
echarts.connect([klineChart, indicatorChart])
```

### 优化后的架构

```
┌─────────────┐                      ┌─────────────┐
│  K 线图     │  <─── connect ───>   │  指标图      │
│ dataZoom[0] │      自动同步         │ dataZoom[0] │
└─────────────┘                      └─────────────┘
     共享组件                             共享组件
```

**优势**：
- ✅ **零配置**：ECharts 原生支持，无需手动同步
- ✅ **零延迟**：原生事件触发，实时同步
- ✅ **零开销**：无轮询，无 CPU 占用
- ✅ **零 Bug**：官方实现，稳定可靠

## 六、技术细节

### ECharts connect API 原理

**官方文档**：https://echarts.apache.org/zh/api.html#echarts.connect

**作用**：
- 连接多个图表实例
- 共享工具栏（toolbox）
- 共享 dataZoom（自动同步）
- 共享 tooltip（联动显示）

**实现机制**：
1. 内部维护一个图表组（group）
2. 监听每个图表的 `dataZoom` 事件
3. 事件触发时自动广播到组内其他图表
4. 其他图表接收事件后自动更新 dataZoom

**核心代码**（ECharts 源码简化版）：
```javascript
function connectAction(groupId, chart) {
    chart.on('dataZoom', function(params) {
        // 广播到同组其他图表
        group.forEach(otherChart => {
            if (otherChart !== chart) {
                otherChart.dispatchAction(params)
            }
        })
    })
}
```

### 为什么移除指标图的 start/end 配置？

**原因**：
1. **connect 会自动同步**：K 线图的 start/end 会自动广播到指标图
2. **避免冲突**：如果指标图也设置 start/end，可能与 connect 的同步产生冲突
3. **简化配置**：只需在 K 线图设置默认值，指标图自动继承

**测试验证**：
```javascript
// K 线图配置
dataZoom: [
    { type: 'inside', start: 75, end: 100 },  // 设置默认值
    { type: 'slider', start: 75, end: 100 }
]

// 指标图配置
dataZoom: [
    { type: 'inside' }  // 不设置 start/end，自动继承 K 线图
]

// 效果：首次渲染时，指标图自动使用 75-100%
```
