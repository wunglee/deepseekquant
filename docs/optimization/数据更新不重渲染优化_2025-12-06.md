# 数据更新不重渲染优化报告

**优化日期**: 2025-12-06  
**优化目标**: 数据加载后仅更新数据，不重新渲染图表  
**优化文件**: `core_bak_refactored/app/quality_monitoring/templates/data_explorer.html`

---

## 一、问题描述

### 用户反馈

> "每次拉取数据后，能否仅仅是更新滚动条的位置，而不是刷新数据窗口？因为数据窗口的变化仅仅与拖拽行为相关，与'后台数据'的获取无关"

### 问题现象

当前实现在无限滚动加载数据后：

1. ✅ 用户拖动到 20% 位置，触发加载
2. 🔄 加载成功后调用 `renderKline(allKlineData, allEvents)`
3. ❌ **整个图表重新渲染**，导致：
   - 数据窗口闪烁
   - 视觉跳动
   - 用户体验差

### 根本原因

```javascript
// ❌ 原代码（第 407 行）
// 重新渲染图表
renderKline(allKlineData, allEvents)
```

**问题**：
- `renderKline()` 会**完全重新渲染**图表（包括配置、样式、事件监听器等）
- 即使 `setOption(option, false)` 使用合并模式，仍会触发重渲染
- 导致数据窗口产生视觉上的"闪烁"

---

## 二、解决方案

### 核心思路

**分离数据更新和图表渲染**：
- **加载新股票**：完整渲染（`renderKline`）
- **无限滚动**：仅更新数据（`updateChartData`）

### 实现策略

#### 策略1：新增 updateChartData 函数

仅更新图表的数据部分，不触发完整重渲染：

```javascript
function updateChartData(data, events) {
    // 处理数据
    const processedData = data.map(...)
    const ohlc = processedData.map(d => [d.open, d.close, d.low, d.high])
    const dates = processedData.map(d => d.date)
    
    // 🔧 仅更新数据，不触发重渲染
    klineChart.setOption({
        xAxis: { data: dates },
        series: [
            { name: 'K线', data: ohlc, markPoint: {...} },
            { name: 'MA5', data: calcMA(processedData, 5) },
            { name: 'MA10', data: calcMA(processedData, 10) },
            { name: 'MA20', data: calcMA(processedData, 20) }
        ]
    }, false)  // false = 合并模式，不重置配置
    
    // 同步更新指标图
    updateIndicatorData(processedData)
}
```

**关键点**：
- 仅更新 `xAxis.data` 和 `series[].data`
- 不更新 `dataZoom`、`grid`、`title` 等配置
- ECharts 智能检测到仅数据变化，不触发完整重渲染

## 三、代码修改详情

### 新增函数1：updateChartData（第 358-415 行）

```javascript
/**
 * 仅更新图表数据（不重新渲染，避免视觉跳动）
 * @param {Array} data - K线数据
 * @param {Array} events - 事件数据
 */
function updateChartData(data, events) {
    try {
        // 处理日期格式
        const processedData = data.map(d => {
            let dateStr = d.date
            if (typeof dateStr === 'string' && dateStr.includes('GMT')) {
                const dt = new Date(dateStr)
                dateStr = dt.toISOString().split('T')[0]
            }
            return { ...d, date: dateStr }
        })
        
        const displayEvents = events || []
        const ohlc = processedData.map(d => [d.open, d.close, d.low, d.high])
        const dates = processedData.map(d => d.date)
        
        // 🔧 仅更新数据，不触发重渲染
        klineChart.setOption({
            xAxis: { data: dates },
            series: [
                {
                    name: 'K线',
                    data: ohlc,
                    markPoint: {
                        data: displayEvents.map(e => {
                            let evtDate = e.date
                            if (typeof evtDate === 'string' && evtDate.includes('GMT')) {
                                evtDate = new Date(evtDate).toISOString().split('T')[0]
                            }
                            return {
                                name: e.title,
                                xAxis: evtDate,
                                yAxis: e.price || 0,
                                symbolSize: e.severity === 'critical' ? 60 : 40,
                                itemStyle: { color: e.impact === 'negative' ? '#ef4444' : '#10b981' }
                            }
                        })
                    }
                },
                { name: 'MA5', data: calcMA(processedData, 5) },
                { name: 'MA10', data: calcMA(processedData, 10) },
                { name: 'MA20', data: calcMA(processedData, 20) }
            ]
        }, false)  // false = 合并模式，不重置配置
        
        // 同步更新指标图
        updateIndicatorData(processedData)
        
        console.log('🔄 已更新图表数据（无重渲染），总计', processedData.length, '条')
    } catch(e) {
        console.error('更新图表数据失败:', e)
    }
}
```

### 新增函数2：updateIndicatorData（第 417-513 行）

```javascript
/**
 * 仅更新指标图数据
 * @param {Array} processedData - 处理后的K线数据
 */
function updateIndicatorData(processedData) {
    try {
        const dates = processedData.map(d => d.date)
        
        if (currentIndicator === 'VOL') {
            indicatorChart.setOption({
                xAxis: { data: dates },
                series: [{ data: processedData.map(d => d.volume) }]
            }, false)
        } else if (currentIndicator === 'MACD') {
            const closePrices = processedData.map(d => d.close)
            const { macdLine, signalLine, histogram } = calculateMACD(closePrices)
            indicatorChart.setOption({
                xAxis: { data: dates },
                series: [
                    { name: 'MACD', data: macdLine },
                    { name: 'Signal', data: signalLine },
                    { name: 'Histogram', data: histogram }
                ]
            }, false)
        } else if (currentIndicator === 'RSI') {
            const closePrices = processedData.map(d => d.close)
            const rsi = calculateRSI(closePrices, 14)
            indicatorChart.setOption({
                xAxis: { data: dates },
                series: [{ data: rsi }]
            }, false)
        } else if (currentIndicator === 'KDJ') {
            const highPrices = processedData.map(d => d.high)
            const lowPrices = processedData.map(d => d.low)
            const closePrices = processedData.map(d => d.close)
            const { k, d, j } = calculateKDJ(highPrices, lowPrices, closePrices, 9)
            indicatorChart.setOption({
                xAxis: { data: dates },
                series: [
                    { name: 'K', data: k },
                    { name: 'D', data: d },
                    { name: 'J', data: j }
                ]
            }, false)
        } else if (currentIndicator === 'OBV') {
            const obv = []
            let obvValue = 0
            for (let i = 0; i < processedData.length; i++) {
                if (i === 0) {
                    obv.push(obvValue)
                } else {
                    const change = processedData[i].close - processedData[i-1].close
                    if (change > 0) {
                        obvValue += processedData[i].volume
                    } else if (change < 0) {
                        obvValue -= processedData[i].volume
                    }
                    obv.push(obvValue)
                }
            }
            indicatorChart.setOption({
                xAxis: { data: dates },
                series: [{ data: obv }]
            }, false)
        }
    } catch(e) {
        console.error('更新指标图数据失败:', e)
    }
}
```

## 七、技术细节

### ECharts setOption 的合并模式

```javascript
chart.setOption(option, notMerge)
```

| notMerge | 行为 | 适用场景 |
|----------|------|----------|
| `true` | 完全替换旧配置 | 切换图表类型、重新初始化 |
| `false` | **合并配置**（默认） | **仅更新部分数据** ✅ |

**合并模式的智能检测**：
- 如果仅更新 `series[].data`，ECharts 智能识别为数据更新，不重建 DOM
- 如果更新 `grid`、`title`、`dataZoom`，ECharts 重建相关组件

### 为什么提取计算函数为全局函数？

**原因**：
1. `updateIndicatorData` 需要调用这些函数
2. `renderIndicator` 也需要调用这些函数
3. 避免重复定义（DRY 原则）

**收益**：
- 减少 312 行重复代码
- 统一逻辑，降低维护成本
- 提升代码可读性
