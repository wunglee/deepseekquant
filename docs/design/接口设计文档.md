## 3. 业务服务接口

```python
# data_fetcher.py（通用数据获取器）
class DataFetcher:
    """通用数据获取器 - 多源历史/实时数据，支持缓存与备用源重试"""

    def __init__(self, config: Dict[str, Any]):
        """
        Args:
            config: 配置字典
                - primary: 主数据源（如 'yahoo'）
                - fallback_sources: 备用数据源列表
                - cache_enabled: 是否启用缓存（默认True）
                - redis.enabled: 是否启用Redis缓存（默认False）
        """

    async def get_historical_data(
        self,
        symbols: List[str],
        period: str = '1y',
        interval: str = '1d',
        data_type: str = 'ohlcv',
        adjustments: bool = True
    ) -> Dict[str, List[MarketData]]:
        """
        获取历史数据（缓存命中→主源→备用源重试）
        
        Args:
            symbols: 股票代码列表
            period: 数据期间（如 '1y'/'6mo'/'max'）
            interval: 数据间隔（如 '1d'/'1wk'/'1mo'）
            data_type: 数据类型（'ohlcv'/'dividends'/'splits'/'all'）
            adjustments: 是否调整价格（分红/拆股）
        
        Returns:
            Dict[str, List[MarketData]]: 每个符号的市场数据列表
        
        Example:
            >>> fetcher = DataFetcher({'primary': 'yahoo'})
            >>> data = await fetcher.get_historical_data(['AAPL'], '1y', '1d', 'ohlcv', True)
            >>> len(data['AAPL']) > 0
            True
        """

    async def get_real_time_data(
        self,
        symbols: List[str],
        data_types: List[str] = None
    ) -> Dict[str, MarketData]:
        """
        获取实时数据（按配置选择实时源，失败时尝试备用实时源）
        
        Args:
            symbols: 股票代码列表
            data_types: 实时数据类型（如 'quote'/'trade'）
        
        Returns:
            Dict[str, MarketData]: 实时市场数据
        """

    async def cleanup(self): ...
    async def __aenter__(self): ...
    async def __aexit__(self, exc_type, exc_val, exc_tb): ...
```

## 4. 公开API（协调器）

```python
# data_processor.py
class DataProcessor:
    """数据处理协调器 - 统一入口路由到获取/验证/质量监控"""

    def __init__(
        self,
        config: Dict[str, Any],
        fetcher: Optional['DataFetcher'] = None,
        validator: Optional['DataValidator'] = None,
        monitor: Optional['DataQualityMonitor'] = None
    ):
        """
        初始化协调器（支持依赖注入）
        
        Args:
            config: 配置字典
            fetcher: 可注入的数据获取器实现（默认 DataFetcher）
            validator: 可注入的数据验证器实现（默认 DataValidator）
            monitor: 可注入的数据质量监控实现（默认 DataQualityMonitor）
        """

    def process(self, data: Dict[str, Any]) -> Dict[str, Any]:
        """
        处理数据请求
        
        Args:
            data: 输入数据字典
                - action: 'fetch' | 'validate' | 'monitor'
                - 其余字段由具体服务使用
        
        Returns:
            Dict[str, Any]: 处理结果（各服务自定义结构）
        
        Example:
            >>> processor = DataProcessor({'primary': 'yahoo'})
            >>> out = processor.process({'action': 'validate', 'data': []})
            >>> isinstance(out, dict)
            True
        """
```

## 5. 依赖注入与装配约定（关键）
- 所有服务类（Fetcher/Validator/Monitor/Reporter）均通过构造函数接收配置与依赖，允许运行期注入替代实现（例如数据适配器、缓存、告警通道）。
- DataProcessor 应支持注入具体实现（例如 DataFetcher、DataValidator、DataQualityMonitor），避免在内部直接构造默认实现。
- 外部数据适配器（Tushare/AKShare/YFinance等）通过统一适配接口注入，不在生产代码中使用测试目录的 Mock。

## 6. 使用示例

```python
config = {
    'primary': 'yahoo',
    'fallback_sources': ['alpha_vantage'],
    'redis': {'enabled': False}
}
processor = DataProcessor(config)

# 获取历史数据
result = asyncio.run(processor.process({'action': 'fetch', 'symbols': ['AAPL'], 'period': '1y'}))

# 验证质量
validation = processor.process({'action': 'validate', 'data': market_data})

# 质量监控（基于策略）
policy = PolicyConfigLoader.load('config/data_quality_policy.json')
monitor = DataQualityMonitor(policy)
report, flags = monitor.validate({'prices': [...], 'returns': [...]})
```

## 7. 边界与注意事项
- 本模块为历史整理的逻辑碎片，部分实现可能不可直接运行；接口文档以“意图与边界”为准。
- 外部依赖（HTTP/Redis/第三方API）需通过注入与适配器隔离；在临时系统中不强制依赖真实服务。
- 严禁在实现代码中引入测试目录 Mock；测试模拟仅存在于 tests/。
