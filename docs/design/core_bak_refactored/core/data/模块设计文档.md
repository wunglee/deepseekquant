# 数据模块（core/data）- 模块设计文档

## 文档元信息
- 文档版本: v0.1（草案）
- 创建日期: 2025-11-28
- 模块定位: 统一的数据质量评估与治理服务（非业务特有逻辑）

## 一、模块定位
- 提供数据质量评估服务，输出统一的质量报告与质量标识，供各业务模块消费。
- 规则与阈值来自专家配置（ask/answer），严禁在代码中设默认值。

## 二、外部协作
- 消费方：core/risk、core/portfolio、core/signal（仅消费 quality_flags，不自定义规则）
- 配置来源：docs/ask.md / docs/answer.md + JSON/YAML 配置文件

## 三、核心组件
- DataQualityPolicy（规则集与阈值，配置驱动）
- DataQualityMonitor（评估器，validate(data) → quality_report, quality_flags）
- PolicyConfigLoader（策略配置加载与校验）
- QualityReport/QualityFlags（输出数据结构）

## 四、数据流
1. 加载策略配置（PolicyConfigLoader）
2. 执行评估（DataQualityMonitor.validate）
3. 输出质量标识（QualityFlags），由业务模块外部化到报告/快照

## 五、迭代路线
- 迭代1：评估服务落地（validate + 报告/标识输出）
- 迭代2：策略配置加载与校验（JSON/YAML + 校验器 + 可选热更新）
