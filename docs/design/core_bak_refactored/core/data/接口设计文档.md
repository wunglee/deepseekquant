# 数据模块（core/data）- 接口设计文档

## 接口概览
- DataQualityMonitor.validate(data: dict) -> (QualityReport, QualityFlags)
- PolicyConfigLoader.load(path: str) -> DataQualityPolicy

## 数据结构
- DataQualityPolicy
  - completeness: { required_fields: ["prices", "returns", "market_data"] }
  - consistency: { type_rules: {...}, range_rules: {...} }
  - timeliness: { max_age_days: int }
  - reliability: { source_whitelist: ["Yahoo", "JoinQuant"], error_rate_threshold: float }
- QualityReport
  - issues: List[Issue]
  - summary: { completeness_ok: bool, consistency_ok: bool, timeliness_ok: bool, reliability_ok: bool }
- QualityFlags
  - flags: { DATA_QUALITY_WARNING: bool, reasons: List[str] }

## 行为约束
- 所有规则与阈值必须来自专家配置；禁止默认值。
- validate 不修改输入数据，不做业务推断，只评估质量。

## 使用示例
```
policy = PolicyConfigLoader.load("config/data_quality_policy.yaml")
monitor = DataQualityMonitor(policy)
report, flags = monitor.validate(dataset)
# 风险模块：仅将 flags 外部化至 report_snapshot
```
