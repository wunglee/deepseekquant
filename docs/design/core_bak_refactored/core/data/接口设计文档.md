## 一、接口概述

### 1.1 接口分类
- 公开API（对外调用）
  - [DataFetcher]（统一数据获取入口）
  - 数据模型：[MarketData]、枚举 [DataSourceType]、[DataFrequency]
- 内部服务接口（模块内协作）
  - 缓存接口：MemoryTTL、LRU、RedisAdapter
  - 认证/凭证：ApiCredentialsManager
  - HTTP客户端：AsyncHttpClient、SyncHttpSession
  - 数据源适配器：YahooProvider、AlphaVantageProvider、IEXProvider 等

### 1.2 调用模式（典型流程）
```
from core_bak_refactored.core.data.data_fetcher import DataFetcher, MarketData

config = {
  'primary': 'yahoo',
  'fallback_sources': ['alpha_vantage'],
  'cache_enabled': True,
  'redis': {'enabled': False}
}
fetcher = DataFetcher(config)
result = await fetcher.get_historical_data(['AAPL','MSFT'], '1y', '1d', 'ohlcv', True)
```

## 二、核心公开API

### 2.1 类 [DataFetcher] - 数据获取协调器

构造函数
- `__init__(config: Dict[str, Any], custom_sources: Optional[Dict[str, Callable]] = None)`
  - 说明：支持依赖注入（custom_sources），配置驱动主/备数据源、缓存、HTTP客户端、Redis等

方法
- `get_historical_data(symbols: List[str], period: str = '1y', interval: str = '1d', data_type: str = 'ohlcv', adjustments: bool = True) -> Dict[str, List[MarketData]]`（async）
  - 功能：并发拉取多标的历史数据，支持主源失败后按优先级回退
  - 错误：网络异常、数据源异常统一记录日志并对单标的降级

- `get_real_time_data(symbols: List[str], data_types: List[str] = None) -> Dict[str, MarketData]`（async）
  - 功能：实时数据拉取，按配置选择数据源（IEX/Polygon/TwelveData等），失败时尝试备用

- `stream_real_time_data(symbols: List[str], callback: Callable[[Dict], None], data_types: List[str] = None)`（async）
  - 功能：实时流式推送（WebSocket），将增量数据回调给调用方

- `get_fundamental_data(symbol: str) -> Dict[str, Any)`（async）
  - 功能：基础面数据聚合（Yahoo、AlphaVantage、其他源）

- `get_market_status() -> Dict[str, Any]`（async）
  - 功能：市场开闭市、波动率状态、板块表现、广度、情绪、数据质量指标汇总

数据质量/监控（公开读取型）
- `get_data_quality_metrics() -> Dict[str, Any]`
  - 功能：返回质量评分维度（完整性/及时性/准确性/一致性等）

### 2.2 数据模型 [MarketData]
- 字段：symbol、timestamp、open、high、low、close、volume、adj_close、dividends、splits、metadata...
- 方法：`to_dict() -> Dict`、`from_dict(data: Dict) -> MarketData`
- 约束：时间戳 ISO 格式；数值型字段非空；metadata保留数据来源信息

### 2.3 枚举
- [DataSourceType]：`yahoo/alpha_vantage/iex_cloud/polygon/twelve_data/...`
- [DataFrequency]：`tick/second/minute/hour/daily/weekly/monthly`

## 三、内部服务接口（协议）

### 3.1 缓存接口
- MemoryTTLCache：`get(key) -> Any | None`、`set(key, value, ttl: int)`
- LRUCache：`get(key) -> Any | None`、`set(key, value)`
- RedisCacheAdapter：`get(key) -> bytes | None`、`setex(key, ttl, bytes)`（压缩+序列化）

### 3.2 认证与凭证
- ApiCredentialsManager：`get(source: str) -> Dict[str, Any]`
  - 字段：api_key、secret_key、access_token、base_url、rate_limit、authentication_type

### 3.3 HTTP客户端
- AsyncHttpClient（aiohttp）：`get(url, timeout) -> Response`、`json()`
- SyncHttpSession（requests）：会话池、重试设置

### 3.4 数据源适配器（示例）
- YahooProvider：`fetch(symbol, period, interval, data_type, adjustments) -> List[MarketData]`
- AlphaVantageProvider：`fetch(symbol, period, interval, data_type, adjustments) -> List[MarketData]`
- 其余源同构（IEX/Polygon/...），统一异常与速率限制策略

## 四、异常处理
- 网络异常：`aiohttp.ClientError`、`requests.RequestException` → 重试或回退
- 配置异常：缺失API密钥/不支持的参数 → `ValueError`
- 解析异常：时间序列缺失/空数据 → 返回 None 并记录日志

---

## 五、性能与SLA
- 并发：对多标的使用 `asyncio.gather`；连接池限制
- 缓存：内存+LRU+Redis三级；命中则直接返回
- 指标：requests_total/failed/cache_hits/misses/avg_response_time/data_points_processed
