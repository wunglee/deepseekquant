## 一、接口概述
- 组件：
  - [DataQualityAPIService]（RESTful API 服务，Flask）
  - [DataQualityDashboard]（可视化仪表板，Flask + WebSocket + ECharts）
- 依赖：领域层 [DataQualityMonitor]（来自 core/data，读取质量数据与性能统计）

---

## 二、API服务端点（[DataQualityAPIService]）
基路径：`/api/v1/*`

- `GET /quality/current`
  - Params: `hours:int=24`
  - Returns: `{status, data: List[quality_point], metadata, timestamp}`

- `GET /quality/report`
  - Params: `period:str='7d'`, `format:str='json|csv'`, `include_details:bool=true`
  - Returns: `{status, report, report_id, timestamp}` 或 CSV 文件

- `GET /alerts`
  - Params: `hours:int=24`, `level:str`, `severity:str`, `data_source:str`, `page:int=1`, `per_page:int=50`
  - Returns: `{status, alerts, pagination, summary, timestamp}`

- `GET /performance`
  - Returns: `{status, performance, timestamp}`（包含系统健康度/趋势/资源利用率/建议）

- `GET /metrics`
  - Params: `type:str='all'`, `time_range:str='24h'`, `aggregation:str='hourly'`
  - Returns: `{status, metrics, metadata, timestamp}`

- `GET /export`
  - Params: `data_type:str='quality|alerts'`, `format:str='json|csv'`, `time_range:str='7d'`
  - Returns: 成功/失败状态（必要时返回附件）

- `GET|PUT /config`
  - GET Returns: `{status, config, timestamp}`
  - PUT Body: `{...}` → Returns: `{status, message, timestamp}`

- `GET /health` / `GET /diagnostics` / `GET /status`
  - Returns: 健康检查/诊断报告/系统状态摘要

- `POST /maintenance`
  - Params: `action='enable|disable'`, `duration:int=3600`
  - Returns: 成功/失败状态

- 错误处理（内置）：404/405/500 → `{status:'error', message, error_code}`

---

## 三、仪表板接口（[DataQualityDashboard]）
- 路由：
  - `GET /` → 返回 HTML（内嵌 CSS/JS/ECharts 初始化）
  - `GET /api/quality-data` → 当前质量数据摘要
  - `GET /api/performance-stats` → 性能统计
  - `GET /api/alerts?hours=24` → 近期警报
  - `GET /api/reports/<report_id>` → 报告数据（占位）
  - `GET /api/export-data?format=json|csv` → 导出质量数据（调用领域层导出）
  - `GET /ws` → WebSocket 端点（订阅/取消订阅/请求数据）

- WebSocket 消息类型：
  - `quality_update` / `alert_update`（服务端广播）
  - 客户端请求：`subscribe|unsubscribe|request_data{quality_data|alerts|performance}`

- 更新线程：`_dashboard_update_worker()` 周期刷新并广播

---

## 四、数据结构与示例
- 质量点：`{timestamp:str, overall_score:float, anomaly_count:int, error_count:int, details:Dict}`
- 性能：`{throughput:float, reliability:float, accuracy:float, timeliness:float, completeness:float, consistency:float}`
- 警报：`{timestamp:str, level:'critical|high|medium|low', message:str, data_source:str}`
