## 🛠 JavaScript 工具库

### 引入方式

```html
<script src="/static/js/common.js"></script>
```

所有工具函数通过 `AppUtils` 全局对象访问。

---

### 主要功能

#### 1. API 请求

```javascript
// GET 请求
const data = await AppUtils.apiRequest('/quality/current');

// POST 请求
const result = await AppUtils.apiRequest('/trigger-check', {
    method: 'POST',
    body: JSON.stringify({ param: 'value' })
});
```

**特性**：
- 自动添加 JSON 头
- 统一错误处理
- 自动显示错误提示

---

#### 2. ECharts 空状态渲染

```javascript
const chart = echarts.init(document.getElementById('myChart'));

// 显示空状态
AppUtils.showEmptyChart(chart, '暂无数据');

// 自定义提示文字
AppUtils.showEmptyChart(chart, '加载中...');
```

**效果**：
- 隐藏坐标轴和图例
- 清空数据系列
- 居中显示文字提示

---

#### 3. 提示框

```javascript
// 成功提示
AppUtils.showToast('操作成功', 'success');

// 错误提示
AppUtils.showToast('操作失败', 'danger');

// 信息提示
AppUtils.showToast('请注意', 'info');
```

**特性**：
- 自动3秒后消失
- 滑入滑出动画
- 右上角固定位置

---

#### 4. 日期格式化

```javascript
// 完整格式
AppUtils.formatDate('2025-12-05T10:30:00');
// 输出: "2025-12-05 10:30:00"

// 自定义格式
AppUtils.formatDate('2025-12-05T10:30:00', 'YYYY-MM-DD');
// 输出: "2025-12-05"
```

---

#### 5. 数字格式化

```javascript
// 保留2位小数
AppUtils.formatNumber(3.14159, 2);
// 输出: "3.14"

// 百分比格式
AppUtils.formatPercent(0.8567, 2);
// 输出: "85.67%"
```

---

#### 6. 表格渲染

```javascript
const data = [
    { name: 'Alice', age: 25, score: 95.5 },
    { name: 'Bob', age: 30, score: 88.0 }
];

const columns = [
    { field: 'name' },
    { field: 'age' },
    { 
        field: 'score',
        format: (value) => value.toFixed(1) + '%'
    }
];

AppUtils.renderTable('myTable', data, columns);
```

---

#### 7. 防抖与节流

```javascript
// 防抖（300ms）
const debouncedSearch = AppUtils.debounce(function(query) {
    console.log('搜索:', query);
}, 300);

// 节流（300ms）
const throttledScroll = AppUtils.throttle(function() {
    console.log('滚动事件');
}, 300);
```

---

#### 8. 系统健康检查

```javascript
// 手动检查
const isHealthy = await AppUtils.checkSystemHealth();

// 自动每30秒检查一次（已自动启用）
```

**效果**：
- 更新顶部导航栏的状态指示器颜色
- 绿色：健康
- 红色：异常

## 📱 响应式适配

所有组件自动适配不同屏幕尺寸：

- **桌面端** (>1024px): 完整导航栏 + 多列布局
- **平板** (768px-1024px): 隐藏导航栏 + 2列布局
- **手机** (<768px): 单列布局

## 🔧 扩展指南

### 添加新的工具函数

编辑 `static/js/common.js`，在 `window.AppUtils` 对象中添加：

```javascript
window.AppUtils = {
    // ... 现有函数 ...
    
    // 新增函数
    customFunction: function() {
        // 实现
    }
};
```

### 添加新的样式组件

编辑 `static/css/common.css`，遵循 BEM 命名规范：

```css
/* 新组件 */
.my-component {
    /* 基础样式 */
}

.my-component__element {
    /* 元素样式 */
}

.my-component--modifier {
    /* 修饰符样式 */
}
```

---

## 📝 注意事项

1. **不要修改核心样式**：如需自定义，使用页面级样式覆盖
2. **保持导航栏一致**：所有页面使用相同的导航栏代码
3. **使用工具函数**：优先使用 `AppUtils` 而非重复实现
4. **测试响应式**：在不同屏幕尺寸下测试页面
