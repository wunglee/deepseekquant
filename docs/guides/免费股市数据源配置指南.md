### 2. **Tushare** ✅ 已实现

**文件**: `core_bak_refactored/core/data/providers/tushare.py`

**特点**:
- ✅ **中国市场专业数据源**（A股、港股）
- ✅ 数据质量高，更新及时
- ✅ 支持财务数据、基本面数据

- ⚠️ 免费用户每天限 **200次调用**（积分制度）

**注册方式**:
1. 访问 [https://tushare.pro/register](https://tushare.pro/register)
2. 注册账号（手机号验证）
3. 获取 Token（在个人中心查看）
4. 配置 Token（见下方）

**配置示例**:
```yaml
# config/dev/data.yml
primary_source: tushare
backup_sources: [yahoo]
cache_enabled: true
cache_ttl: 3600

# 环境变量配置 Token（推荐）
# export TUSHARE_TOKEN='your_token_here'
```

**或使用配置文件**:
```yaml
# config/dev/credentials.yml
tushare:
  token: 'your_tushare_token_here'
```

**Python 使用**:
```python
from core_bak_refactored.core.data.providers.tushare import TushareDataProvider

# 方式1: 从环境变量读取 Token
provider = TushareDataProvider(fallback_to_mock=True)

# 方式2: 直接传入 Token
provider = TushareDataProvider(token='your_token', fallback_to_mock=True)

data = provider.get_index_prices('000300.SH', '2024-01-01', '2024-12-01')
print(data.head())
```

**支持的数据类型**:
- ✅ A股指数（沪深300、上证指数、深证成指等）
- ✅ A股个股（日线、分钟线）

## 集成新数据源

如果您想将 **AKShare** 或 **Baostock** 集成到项目中，请按以下步骤操作：

### 步骤1：创建数据提供者类

在 `core_bak_refactored/core/data/providers/` 目录下创建新文件：

**示例：`akshare_provider.py`**

```python
"""
AKShare数据提供者 - A股/港股/美股数据源
实现HistoricalDataProvider接口
"""

import pandas as pd
import numpy as np
from typing import Dict, Optional, Union
from datetime import datetime
import logging

logger = logging.getLogger('DeepSeekQuant.AKShareProvider')


class AKShareDataProvider:
    """
    AKShare数据提供者
    
    功能：
    - 通过AKShare获取全市场历史数据
    - 支持A股、港股、美股
    - 数据标准化和质量验证
    """
    
    def __init__(self, fallback_to_mock: bool = True):
        """初始化AKShare数据提供者"""
        self.fallback = fallback_to_mock
        
        try:
            import akshare as ak
            self.ak = ak
            logger.info("AKShareDataProvider initialized successfully")
        except ImportError:
            logger.warning("akshare not installed")
            self.ak = None
            if not self.fallback:
                raise RuntimeError("akshare library not available and fallback disabled")
    
    def get_index_prices(self, index_id: str, start_date: str, end_date: str) -> pd.DataFrame:
        """
        获取指数价格数据
        
        Args:
            index_id: 指数代码（如'000300.SH'沪深300）
            start_date: 开始日期 'YYYY-MM-DD'
            end_date: 结束日期 'YYYY-MM-DD'
        
        Returns:
            DataFrame with columns: ['date', 'close', 'volume']
        """
        if self.ak is None:
            if self.fallback:
                return self._fallback_to_mock(index_id, start_date, end_date)
            else:
                raise RuntimeError("AKShare not available and fallback disabled")
        
        try:
            # 映射指数代码
            symbol = self._map_index_to_akshare(index_id)
            logger.info(f"Fetching data for {index_id} (mapped to {symbol})")
            
            # 调用AKShare API
            df = self.ak.stock_zh_index_daily(symbol=symbol)
            
            # 筛选日期范围
            df = df[(df['date'] >= start_date) & (df['date'] <= end_date)]
            
            # 标准化格式
            standardized_data = pd.DataFrame({
                'date': pd.to_datetime(df['date']),
                'close': df['close'].astype(float),
                'volume': df['volume'].astype(float) if 'volume' in df.columns else 0
            })
            
            logger.info(f"Successfully fetched {len(standardized_data)} rows for {index_id}")
            return standardized_data
            
        except Exception as e:
            logger.warning(f"AKShare failed for {index_id}: {e}")
            if self.fallback:
                return self._fallback_to_mock(index_id, start_date, end_date)
            else:
                raise ValueError(f"Failed to fetch data for {index_id}: {e}")
    
    def _map_index_to_akshare(self, index_id: str) -> str:
        """映射指数代码到AKShare格式"""
        mapping = {
            '000300.SH': 'sh000300',  # 沪深300
            '000001.SH': 'sh000001',  # 上证指数
            '399001.SZ': 'sz399001',  # 深证成指
            '000905.SH': 'sh000905',  # 中证500
        }
        return mapping.get(index_id, index_id)
    
    def _fallback_to_mock(self, index_id: str, start_date: str, end_date: str) -> pd.DataFrame:
        """回退到Mock数据"""
        from tests.fixtures.core.data.mock_historical_data_provider import MockHistoricalDataProvider
        mock = MockHistoricalDataProvider()
        return mock.get_index_prices(index_id, start_date, end_date)
```

## 常见问题

### Q1: 哪个数据源最适合我？

**回答**:
- **开发/测试**: Mock 数据源（无需网络）
- **A股分析**: AKShare（推荐，无限制）或 Tushare（专业，有限制）
- **全球市场**: Yahoo Finance（美股、港股、指数）
- **生产环境**: 多源冗余配置（primary + backup）

---

### Q2: Tushare 每天200次调用不够用怎么办？

**解决方案**:
1. **启用缓存**（推荐）
   ```yaml
   cache_enabled: true
   cache_ttl: 3600  # 缓存1小时
   ```

2. **配置备用数据源**
   ```yaml
   primary_source: tushare
   backup_sources: [akshare, yahoo]  # 超限时自动切换
   ```

3. **升级积分**  
   在 Tushare 平台完成任务（分享、邀请）可提高积分，获得更多调用次数

4. **切换到 AKShare**  
   AKShare 无调用限制，数据同样丰富

---

### Q3: 国内访问 Yahoo Finance 很慢怎么办？

**解决方案**:
1. **优先使用国内数据源**
   ```yaml
   primary_source: akshare
   backup_sources: [tushare, yahoo]
   ```

2. **配置代理**（如果有）
   ```python
   import os
   ```

## 推荐配置方案

### 🏆 方案1：开发环境（无需网络）

```yaml
# config/dev/data.yml
primary_source: mock
backup_sources: []
cache_enabled: false
```

**优点**: 稳定、快速、可复现  
**缺点**: 非真实数据

---

### 🏆 方案2：A股量化（推荐）

```yaml
# config/dev/data.yml
primary_source: akshare
backup_sources: [tushare, mock]
cache_enabled: true
cache_ttl: 3600
```

**优点**: 免费、无限制、数据全  
**缺点**: 依赖第三方网站

---

### 🏆 方案3：全球市场

```yaml
# config/dev/data.yml
primary_source: yahoo
backup_sources: [akshare, mock]
cache_enabled: true
cache_ttl: 3600
```

**优点**: 覆盖全球市场  
**缺点**: 国内访问可能较慢

---

### 🏆 方案4：生产环境（高可用）

```yaml
# config/dev/data.yml
primary_source: tushare
backup_sources: [akshare, yahoo, mock]
cache_enabled: true
cache_ttl: 7200
max_retries: 3
```

**优点**: 多源冗余，高可用  
**缺点**: 配置复杂
