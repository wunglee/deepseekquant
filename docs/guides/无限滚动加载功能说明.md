# Explorer 页面无限滚动加载功能

## 功能概述

在 Explorer 页面（`/explorer`）中实现了无限滚动加载历史K线数据的功能。当用户向左拖动数据窗口到达边界时，系统会自动加载更早的历史数据。

## 实现方案

### 阶段1：前端实现（已完成）✅

#### 1. 边界检测逻辑
- **位置**：`data_explorer.html` 第 237-282 行
- **功能**：每 100ms 检测 dataZoom 的 `start` 值
- **触发条件**：`start < 5%` 且未在加载中且有更多数据
- **防抖机制**：使用 `isLoadingMore` 标志防止并发加载

```javascript
// 检测左边界触发：start < 5% 且未在加载且有更多数据
if (kZoom.start < 5 && !isLoadingMore && hasMoreData) {
    console.log('触发加载更多：start =', kZoom.start)
    isLoadingMore = true
    loadMoreHistoryData(function(success) {
        isLoadingMore = false
        if (!success) {
            hasMoreData = false
            console.log('已到达最早数据')
        }
    })
}
```

#### 2. 真实API调用
- **位置**：`data_explorer.html` 第 297-354 行
- **API端点**：`/api/v1/data/kline`
- **参数**：
  - `symbol`: 指数/股票代码
  - `period`: 周期（daily/weekly/monthly）
  - `count`: 加载数据条数（默认60）
  - `before`: 获取此日期之前的数据（YYYY-MM-DD格式）

```javascript
function loadMoreHistoryData(callback) {
    // 获取最早的日期
    const earliestData = allKlineData[0]
    const beforeDate = earliestData.date  // 'YYYY-MM-DD' 格式
    
    // 构建API URL
    const url = `/api/v1/data/kline?symbol=${encodeURIComponent(currentIndex.id)}&period=${currentPeriod}&count=60&before=${beforeDate}`
    
    // 调用API并处理响应
    fetch(url)
        .then(r => r.json())
        .then(res => {
            const newData = res.data || []
            const newEvents = res.events || []
            
            // 合并数据（新数据插入到前面）
            const oldLength = allKlineData.length
            allKlineData = newData.concat(allKlineData)
            allEvents = newEvents.concat(allEvents)
            
            // 调整 dataZoom 位置（保持视图不跳跃）
            adjustDataZoomAfterPrepend(oldLength, newData.length)
            
            // 重新渲染图表
            renderKline(allKlineData, allEvents)
            
            callback(true)
        })
}
```

#### 3. DataZoom 位置调整
- **位置**：`data_explorer.html` 第 361-403 行
- **功能**：在数据前置后保持用户当前查看的数据区域不跳跃
- **算法**：
  1. 计算原数据区间在新数组中的位置（向后偏移）
  2. 计算新的 start/end 百分比
  3. 同时更新K线图和指标图的 dataZoom

```javascript
function adjustDataZoomAfterPrepend(oldLength, prependLength) {
    const oldZoom = option.dataZoom[0]
    const newLength = oldLength + prependLength
    
    // 计算新的 start 和 end（百分比）
    const oldStartIndex = Math.floor((oldZoom.start || 0) / 100 * oldLength)
    const oldEndIndex = Math.floor((oldZoom.end || 100) / 100 * oldLength)
    
    const newStartIndex = oldStartIndex + prependLength
    const newEndIndex = oldEndIndex + prependLength
    
    const newStart = (newStartIndex / newLength) * 100
    const newEnd = (newEndIndex / newLength) * 100
    
    // 更新 dataZoom
    klineChart.dispatchAction({
        type: 'dataZoom',
        dataZoomIndex: 0,
        start: newStart,
        end: newEnd
    })
    
    // 同步到指标图
    indicatorChart.dispatchAction({...})
}
```

#### 4. 全局数据存储
- **位置**：`data_explorer.html` 第 410-412 行
- **变量**：
  - `allKlineData`: 存储所有K线数据
  - `allEvents`: 存储所有事件数据


## 使用方法

### 1. 启动服务
```bash
python -m core_bak_refactored.app.main
```

### 2. 访问页面
```
http://localhost:5001/explorer
```

### 3. 触发加载
1. 选择一个指数/股票（默认加载最近120条数据）
2. 向左拖动数据窗口，直到 `start < 5%`
3. 系统自动加载更早的60条数据
4. 视图保持不跳跃，用户体验流畅

- ✅ 使用防抖机制避免重复加载

### 2. 用户体验
- ✅ 视图保持不跳跃
- ✅ K线图和指标图同步更新

- ✅ 到达边界时自动停止

### 3. 数据管理
- ✅ 全局数据存储（`allKlineData`、`allEvents`）
- ✅ 新数据前置合并
- ✅ 事件数据同步更新

### 4. 兼容性
- ✅ 支持所有周期（daily/weekly/monthly）
- ✅ 支持Mock数据源（仅当显式传入 `mock=1` 参数时）
- ✅ 支持真实数据源（生产环境默认）

## 注意事项

1. **边界检测阈值**：当前设置为 `start < 5%`，可根据需要调整
2. **每次加载数量**：当前为60条，可通过修改 `count` 参数调整
3. **防抖机制**：使用 `isLoadingMore` 标志，确保同时只有一个加载请求
4. **Mock数据源**：仅当显式传入 `mock=1` 参数时使用
5. **生产环境**：不会自动降级为Mock数据，数据获取失败时返回错误（`DATA_FETCH_FAILED`）
6. **网络延迟**：在慢网络下，用户可能需要等待加载完成
