## 📖 规范文件说明

### 1. PECIFICATIONS.md（主规范文件）

**文件路径**: `.qoder/rules/PECIFICATIONS.md`

**定位**: 项目开发的核心规范文档，所有开发工作的指导手册

**主要内容**:
- 🔴 最高优先级要求（语言、业务逻辑咨询）
- 🎯 系统架构背景（三个系统的关系与边界）
- 📋 核心原则（阶段验收、小步迭代、文档同步）
- 🔄 开发工作流程（ask/answer流程、Git工作流）
- 📝 **文档规范**（引用ask生成规范）
- 🧪 测试规范（命名约定、覆盖率要求）
- 🔧 **代码重构规范**（引用优化策略文档）

**使用场景**:
- ✅ AI执行任务前必读
- ✅ 新成员加入时的培训材料
- ✅ 代码评审时的检查清单
- ✅ 规范更新时的参考基准

**特点**:
- 涵盖全面，覆盖开发全流程
- 强制执行，带自检清单
- 结构化组织，便于快速查找

## 🔗 规范文件之间的关系

```
PECIFICATIONS.md (主规范)
    │
    ├─→ ASK_GENERATION_SPEC.md (ask生成规范)
    │   └─→ 详细的ask结构、写作要求、校验规则
    │
    ├─→ CODE_OPTIMIZATION_STRATEGY.md (代码优化策略)
    │   └─→ 详细的优化流程、检测方法、验收标准
    │
    └─→ (未来可能的其他专项规范)
        ├─→ API_DESIGN_GUIDELINES.md
        ├─→ TESTING_STRATEGY.md
        └─→ DOCUMENTATION_STANDARDS.md
```

**设计思路**:
- **主规范**: 提供概览和核心要求
- **专项规范**: 深入细节和执行流程
- **引用机制**: 主规范引用专项规范，避免冗余

## 📌 使用指南

### 对于AI助手

1. **每次任务前必读**: `PECIFICATIONS.md`
2. **生成ask.md时参考**: `ASK_GENERATION_SPEC.md`
3. **执行优化任务时参考**: `CODE_OPTIMIZATION_STRATEGY.md`
4. **遵循引用链**: 主规范 → 专项规范 → 执行细节

### 对于开发者

1. **快速入门**: 先读 `PECIFICATIONS.md` 核心章节
2. **深入学习**: 根据需要阅读专项规范文档
3. **实践应用**: 参考案例章节学习最佳实践

### 对于规范维护者

1. **更新原则**: 通用内容放主规范，专项细节放专项文档
2. **版本控制**: 每次更新记录版本号和修订历史
3. **一致性检查**: 确保主规范与专项规范的引用关系正确
